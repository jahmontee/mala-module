# Validation scope

Release identity is 0.2.0-beta.1, compatibility revision2. The preparation
receipts bind final source/archive hashes and completed checks.

Earlier public beta.6 USB installation, postboot verification, rollback and
extra no-repeat boots passed on one Hector. That trial used a pre-Mala 407 SD
backup with existing internal settings. It was not a fresh vendor-flash test.
The v2 UI was privately deployed and visually approved later, with verified
installed files and preserved presets/services. Those were private deployments.

Current computer checks cover the native retained 58-port DSP and real Qt5
editor/bridge with native Beads response lookup, including fresh defaults,
quality, Freeze/Seed/Latch, MIDI targets and layout. The updated screenshot is
rendered from actual source with simulated host state.

Disposable transaction/USB-worker checks cover installation, in-place update,
independent removal, postboot idempotence, authenticated catalog migration,
metadata/user-data preservation and interrupted recovery. The extracted-kit
matrix uses real reviewed payload bytes, with hardware identity, mounts,
services and reboot simulated. Archive checks cover checksums, payload closure,
complete corresponding source and unrelated binary exclusion. Read the final
receipts for exact completed counts and hashes.

**These exact v2 USB install/reboot/rollback kits have no physical Hector trial.**
The owner requested computer-only preparation. Earlier beta.6 USB and private
v2 UI evidence cannot substitute for it. GitHub CI is pending on the final
uploaded source commit. Long-run audio/touch/MIDI/CV, frozen-buffer recall,
loaded-patch headroom and future/private combinations remain unqualified.
No hardware CPU improvement or power-loss certification follows from packaging.
